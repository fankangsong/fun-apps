# 跳一跳（jump-jump）设计文档

> 日期：2026-08-28
> 状态：已与需求方逐节确认（玩法定位 / 视觉呈现 / 彩蛋范围 / 技术方案 A）
> 技术栈：原生 HTML / CSS / JavaScript + p5.js（WEBGL）+ Matter.js，本地 `assets/` 引入，双击离线运行

---

## 1. 背景与定位

复刻微信「跳一跳」的单人经典玩法，视觉采用本仓库 Memphis 设计系统（`docs/DESIGN.md`）。

- **玩法定位**：忠实复刻单人经典，不加对战、不加道具系统；先把核心手感做扎实。
- **视觉呈现**：p5 WEBGL 真 3D——方块用真 3D `box()` / `cylinder()`，正交相机约 45° 俯视。
- **彩蛋范围**：中心连击加分 + 三种 Memphis 换皮特殊方块停留彩蛋。
- **技术方案**：混合模式（方案 A）——蓄力跳跃阶段手写解析抛物线保证手感确定，落地后的物理表现（站稳 / 边缘倾倒 / 翻滚坠落）交给 Matter.js 真实模拟。

### 为什么是混合模式

- 原版核心是「蓄力时长 → 跳距」的确定性映射；解析抛物线落点精确可复现，连击判定不受物理噪声干扰，手感参数可独立调。
- 落地瞬间的「倒不倒」由 Matter 按刚体质心/摩擦自然演化，不需要手写倾倒动画。
- 各库各司其职：p5 管渲染与相机，解析抛物线管「跳」，Matter 管「落」。

## 2. 玩法规则

### 2.1 基本循环

按住屏幕任意处（桌面为按住鼠标）蓄力 → 棋子下蹲压缩、蓄力圈扩散 → 松手起跳，沿抛物线飞向下一方块 → 落点判定得分 → 镜头平移 → 生成下一方块。

- 蓄力时长线性映射跳距，**1.2 秒封顶**（达到后不再增长）。
- 棋子蓄力时 Y 轴压缩（squash），起跳瞬间拉伸（stretch）。

### 2.2 方向与难度

- 新方块随机沿世界 X 或 Z 轴延伸（画面上的左前 / 右前两个方向）。
- 跳距随分数逐渐拉大、平台尺寸逐渐缩小（带随机微扰），越跳越难。
- 场上只保留当前方块的前后各约 2 个，其余回收。

### 2.3 得分规则（忠实原版）

| 情形 | 得分 | 说明 |
|---|---|---|
| 普通落点 | +1 | 落在平台范围内但不在中心 |
| 中心落点 | 连击 +2 / +4 / +6 / … | 落点距方块中心 < 判定半径时进入连击并逐次递增，音调逐级升高；未踩中中心即清零 |
| 彩蛋方块 | +5 / +15 / +30 | 落在其上**原地停留 1.0 秒**（`config.js` 可调）触发，触发一次后变普通方块 |
| 落回当前平台 | 0 | 蓄力过小落回原平台：不加分、连击清零，可直接再次起跳 |

### 2.4 彩蛋方块（Memphis 换皮）

| 方块 | 分值 | 表现 |
|---|---|---|
| 唱片机 | +5 | 停留时黑胶唱片旋转 + 短旋律 |
| 魔方 | +15 | 停留时方块自旋 + 提示飘字 |
| 音乐盒 | +30 | 停留时播放一段完整旋律 |

- 出现概率约 1/8，不连续出现。
- 彩蛋只是渲染层差异 + 停留计时器，物理形状与普通方块一致。
- 停留期间再次按下视为放弃彩蛋、立即蓄力起跳。

### 2.5 失败判定

- 落点完全在平台外 → 翻滚坠落。
- 落在边缘、棋子中心超出平台 → Matter 自然倾倒。
- 身体倾斜角超过阈值即判负，弹出结算卡（本局得分、最高分、重开按钮）。

### 2.6 音效

WebAudio 现场合成，不引音频文件：蓄力上升音、起跳「啵」、落地、连击音阶递升、彩蛋旋律、失败音。首次触摸手势时创建 / `resume()` AudioContext（iOS 自动播放限制）；创建失败则静默降级，不影响游戏。

### 2.7 持久化

最高分存 `localStorage`，读写均包 try/catch（Safari 隐私模式会抛错）。

## 3. 技术架构

### 3.1 目录与文件

新建 `jump-jump/`，`index.html` 依次引入 `../assets/p5.min.js`（前置 `p5.disableFriendlyErrors = true`）与 `../assets/matter.min.js`，再按仓库惯例顺序加载：

| 文件 | 职责 |
|---|---|
| `config.js` | 全部可调参数：蓄力曲线、重力、平台尺寸/间距随分数演进、连击判定半径、彩蛋概率与分值、Memphis 配色表 |
| `state.js` | 状态机（`idle → aiming → flying → settling → next → gameover`）、得分/连击、最高分读写 |
| `physics.js` | 蓄力抛物线解析推进 + 落点判定；落地移交 Matter：刚体创建/重置、碰撞事件、站稳与倾倒检测 |
| `input.js` | Pointer Events 统一收集按下/松开（`pointercancel` 对称清理），驱动蓄力；首次手势解锁音频 |
| `render.js` | WEBGL 场景：正交相机与跟随缓动、方块/棋子/假阴影绘制、Memphis 五色循环 |
| `main.js` | p5 `setup/draw`、`windowResized`、`visibilitychange` 暂停恢复、HUD 卡片控制 |

### 3.2 坐标系与相机

- p5 WEBGL：Y 向上，XZ 为地面平面。
- 相机：`ortho()` 正交投影，俯仰约 45°、方位角约 -45°；注视点在当前方块与下一方块之间，随状态切换缓动插值（lerp）跟随。

### 3.3 跳跃与物理接管

1. `aiming`：记录按住时长 → 映射初速度 `v0`（水平分量指向下一方块方向，封顶 1.2s）。
2. `flying`：不走引擎，每帧按 `dt` 解析推进（水平匀速 + 竖直 `v0y - g·t`）。
3. 落地检测：棋子底面触及**任意**平台（当前或下一个）顶面高度、且 XZ 在该平台范围内（解析阶段的平面几何判定）；若越过平台顶面高度后 XZ 始终出界 → 继续下坠，低于顶面阈值时以无支撑状态移交 Matter 翻滚坠落并判负。
4. 落点判定：先按 2.3 计分（距中心平面距离），再创建 Matter box 刚体、继承位置与水平速度，进入 `settling`。
5. `settling`：每帧 `Engine.update(dt)`；碰撞事件 + 运动学阈值判定——速度低于阈值且姿态直立 → `next`；倾斜角超阈值 → `gameover`。
6. `next`：镜头缓动平移、生成新方块、回收旧方块，回到 `aiming`。

### 3.4 平台管理

- 方块为 Matter 静态刚体（box / cylinder 两种形状随机；Matter 无原生圆柱，用 `Bodies.polygon` 16 边近似），棋子为动态 box 刚体（仅 `settling` 阶段存在于世界中）。
- 环形窗口：只保留当前 ±2 个方块；回收延迟到帧末队列统一 `World.remove`（见 4.1）。
- 难度参数（间距上下限、尺寸区间）全部集中在 `config.js`，随分数线性演进。

### 3.5 渲染与 HUD

- **3D 场景**：Memphis 五色（coral / teal / sun / blue / pink）按索引循环分配给方块，墨黑描边勾棱边；棋子为「圆柱身 + 球头」黑描边造型；假阴影为地面椭圆，随棋子高度缩放并淡出。
- **HUD**：HTML 覆盖层——当前分数、连击飘字、开始卡与结算卡，按 `docs/DESIGN.md` 贴纸卡片风格（纸色底、硬阴影、倾斜、黑字幕条）。
- 蓄力进度用棋子脚下扩散的圆环表现（3D 内绘制），不做屏幕进度条。

### 3.6 兼容要点（对照 AGENTS.md 强制项）

- `<head>` 三件套 meta（charset / viewport / apple-mobile-web-app-capable）。
- 画布 `touch-action: none`；HUD 按钮类元素 `touch-action: manipulation`；结算卡区域 `pan-y` 不需要（无滚动内容）。
- 固定定位容器 `env(safe-area-inset-*)` 留白；`html, body { overflow: hidden }`。
- `windowResized()` 调 `resizeCanvas(innerWidth, innerHeight)` 并重算 `ortho()` 视锥；物理世界坐标与屏幕解耦，无需重建刚体。
- `pixelDensity(displayDensity())` 保持 p5 默认，保证高分屏清晰。
- `visibilitychange` 暂停；恢复按真实 `deltaTime` 推进（钳制上限，见 4.3）。
- 长 press 防系统菜单：`-webkit-touch-callout: none`、`user-select: none`、`overscroll-behavior: none`。
- 桌面纯鼠标可完成全部操作；键盘不作为必要输入。

## 4. 错误处理

### 4.1 Matter 生命周期

碰撞回调内不移除任何刚体；旧平台回收统一入帧末队列，在回调外执行 `World.remove`，避免迭代中修改世界。

### 4.2 指针打断

单指游戏，只认第一根按下的 `pointerId`；`pointercancel`（来电 / 系统手势打断）时取消本次蓄力、棋子恢复站立，**绝不起跳**；up / cancel 对称清理。

### 4.3 帧时间与后台

- `visibilitychange` 隐藏时冻结 `Engine.update` 与抛物线推进。
- 恢复后 `dt` 按真实时间差计算并**钳制上限 50ms**；`dt` 异常（0 / 负 / 超限）跳过该帧，杜绝瞬移。

### 4.4 降级

- `localStorage` 读写 try/catch，失败时最高分仅存内存。
- AudioContext 创建或 `resume()` 失败时静默降级，游戏无音效可正常玩。

## 5. 验收测试

1. 双击 `jump-jump/index.html` 离线可玩，控制台无报错。
2. 手感确定性：同一蓄力时长落点恒定；蓄力 1.2s 封顶不再增长。
3. 桌面 Chrome 纯鼠标跑通完整循环：蓄力 → 跳 → 中心连击 → 彩蛋停留 → 边缘倾倒 → 结算重开。
4. DevTools 拉到 320px 宽：HUD 与画布不破版。
5. 真机 iPad：横竖屏旋转、分屏 1/3 宽各验一次；纯触摸完成全部玩法；双指同时按不缩放不滚动；长按蓄力不弹系统菜单、不选中文本。
6. 切后台再切回：画面无瞬移、连击状态不丢。
7. 根目录 `index.html` 的 `GAMES` 数组已注册（`dir / entry / icon / name / desc / tags`）。
